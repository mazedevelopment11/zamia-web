# Zamia Company website

Static site — no build step.

## Publish on GitHub Pages
1. Upload everything in this folder to the root of the repo (keep the `assets` folder).
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. Live in ~1 minute at **https://mazedevelopment11.github.io/zamia-web/**
